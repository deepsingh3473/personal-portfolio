# 💼 Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, projects, and experiences as a developer. It's designed to be responsive, user-friendly, and visually appealing.

## 🚀 Live Demo

Check out the live version here:  
👉 [deepsingh-portfolio.vercel.app](https://deepsingh-portfolio.vercel.app/)

## 🛠️ Built With

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## 📂 Features

- 📄 Multi-page layout (Home, About, Projects, Certificates, Education, Resume)
- 💻 Modern, responsive design
- 🖼️ Project and certificate gallery
- 📄 Downloadable resume
- 🔗 Social and contact links
